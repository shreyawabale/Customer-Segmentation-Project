# Customer Segmentation Using RFM Analysis and K-Means

## 📌 Project Overview

This project performs customer segmentation using the RFM (Recency, Frequency, Monetary) analysis technique and K-Means clustering.

The objective is to group customers based on their purchasing behavior and identify meaningful customer segments that can support targeted marketing and business decisions.

The project uses the Tableau Superstore dataset and Python-based machine learning techniques.

---

## 🎯 Objectives

- Analyze customer purchasing behavior.
- Calculate Recency, Frequency, and Monetary values.
- Segment customers using K-Means clustering.
- Determine the optimal number of customer clusters.
- Evaluate clustering quality using Silhouette Score.
- Visualize customer segments.
- Identify customer groups for targeted marketing strategies.

---

## 📊 Dataset

Dataset: Tableau Superstore Dataset

The dataset contains sales transaction information including:

- Customer ID
- Customer Name
- Order ID
- Order Date
- Sales
- Quantity
- Profit
- Category
- Region
- Segment
- State
- City

The dataset contains 10,194 transaction records and 804 unique customers.

---

## 🔍 Methodology

### 1. Data Loading

The Orders sheet from the Superstore Excel dataset is loaded using Pandas.

### 2. RFM Analysis

Three customer-level features are calculated:

#### Recency
Number of days since the customer's most recent purchase.

#### Frequency
Number of unique orders placed by the customer.

#### Monetary
Total sales generated by the customer.

### 3. Data Transformation

Log transformation is applied to the RFM features to reduce the effect of highly skewed values.

### 4. Feature Scaling

StandardScaler is used to standardize the RFM features before clustering.

### 5. K-Means Clustering

K-Means clustering is tested for K values from 2 to 6.

### 6. Cluster Evaluation

Two techniques are used:

- Elbow Method
- Silhouette Score

The highest Silhouette Score was obtained for:

**K = 2**

Silhouette Score:

**0.354**

Therefore, two customer segments were selected.

---

## 👥 Customer Segments

The analysis identified two major customer segments:

### 🏆 Champions

Customers with relatively higher purchase frequency and monetary value.

These customers are valuable and can be targeted with:

- Loyalty rewards
- Premium offers
- Cross-selling
- Upselling
- Exclusive promotions

### 🤝 Loyal Customers

Customers with comparatively lower purchase frequency and monetary value than the Champions group.

These customers can be encouraged through:

- Personalized offers
- Discount campaigns
- Product recommendations
- Repeat-purchase incentives
